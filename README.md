# 🥤 Coca-Cola Inspired Frontend Website

## 📌 Project Overview

This project is a **modern, responsive Coca-Cola-inspired corporate website** developed using **HTML5, CSS3, and JavaScript**. The website focuses on creating a visually engaging user interface with a clean layout, bold typography, responsive sections, interactive navigation elements, and animated components.

The website presents a brand-focused landing page containing a navigation bar, hero section, product portfolio, global growth statistics, graphical data representation, and a structured footer.

The project was developed to practice **frontend development, responsive UI design, website structuring, CSS styling, JavaScript integration, and frontend animations**.

## 🛠️ Technologies Used

* **HTML5** – Website structure and semantic content
* **CSS3** – Styling, layouts, responsive design, and visual effects
* **JavaScript** – Frontend interaction and animation initialization
* **AOS (Animate On Scroll)** – Scroll-based UI animations
* **Font/External CDN Resources** – Used for frontend assets and animation library integration
